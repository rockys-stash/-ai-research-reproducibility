This script evaluates ridge regression performance on the diabetes dataset from scikit-learn, comparing the original feature set with a version that includes degree-2 polynomial features. It performs 5-fold cross-validation and computes the mean R² score for both models. The results show that adding polynomial features leads to a very small but statistically detectable improvement in R² (by about 0.0004), suggesting that while the improvement is minimal, the polynomial features do not harm performance and may capture subtle nonlinear patterns. However, given the small magnitude of the gain, the added complexity does not significantly improve predictive performance in this dataset. The results are reported in a JSON file named results.json.
