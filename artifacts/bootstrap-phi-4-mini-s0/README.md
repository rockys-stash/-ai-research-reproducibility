This script estimates the difference in mean alcohol content between wine class 0 and wine class 1 using bootstrap resampling. It calculates a 95% confidence interval for the difference and checks if class 0 has higher alcohol content than class 1. The results are saved in a JSON file named 'results.json'. The mean difference is 1.4660133683456706, with a 95% confidence interval ranging from 1.292728395798521 to 1.6373785509668184. The conclusion is that class 0 has a significantly higher mean alcohol content than class 1.
